# كيس للكتب | Kees Books (Demo)

نسخة تجريبية لموقع متجر **كيس** للكتب والروايات، مُعدّة للعرض على فريق المتجر.

> داخل الكتب… خارج العالم

## التشغيل

الموقع ملف واحد: `index.html`. افتحه مباشرة في المتصفح، أو انشره على GitHub Pages.

لا يحتاج سيرفر ولا قاعدة بيانات. كل البيانات (الكتب، العروض، الآراء، الإعدادات، الإحصائيات) محفوظة في `localStorage` داخل المتصفح.

## ما يحتويه

**الواجهة العامة**
- رف كتب تفاعلي في الواجهة، والضغط على أي كتاب يفتح تفاصيله
- العروض مع صورة لكل عرض (رفع من الجهاز أو رابط سحابي)
- الكتب المميزة (٥ كتب يختارها المسؤول)
- كل الكتب: بحث، فلترة حسب الموضوع والحالة، ترتيب، و٢٥ كتاباً في كل صفحة
- زر «طلب الكتاب» يفتح واتساب برسالة جاهزة فيها اسم الكتاب وسعره
- نموذج آراء الزوار (تظهر بعد موافقة المسؤول)
- عنّا، وتواصل معنا
- وضع فاتح وداكن

**لوحة التحكم** (من زر «لوحة التحكم» في أسفل الصفحة)
- نظرة عامة: الزيارات، المشاهدات، ضغطات الطلب، الأكثر طلباً ومشاهدة
- الكتب: إضافة وتعديل وحذف، تعديل السعر والحالة مباشرة، روابط صور الأغلفة
- آراء الزوار: موافقة ورفض وإخفاء
- العروض: نشر وتعديل وحذف مع معاينة حيّة
- الإعدادات: رقم واتساب، رقم احتياطي، البريد، روابط التواصل، سنة البداية

## المكتبات

- [GSAP](https://gsap.com/) لحركة الواجهة
- [Lenis](https://lenis.dev/) للتمرير الناعم
- خطوط Google: Aref Ruqaa و IBM Plex Sans Arabic

## النسخة الحقيقية (المخطط لها)

- الواجهة: Next.js + TypeScript
- الخلفية: ASP.NET Core Web API + Microsoft SQL Server
- الحماية: JWT
- الصور: Supabase Storage
